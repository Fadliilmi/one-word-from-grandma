One word a grandma would text about AI: **contraption**. Grandmas don't say "artificial intelligence" — they say "that contraption" about any confusing machine in the house. Warm, a little baffled, funny in one word, tied to machines, and fresher than the obvious picks. The program scores a short list of grandma words against the judge's own criteria and writes the winner to `/output/entry.txt`.

## Run it

```sh
node main.ts
```
